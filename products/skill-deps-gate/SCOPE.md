# skill-deps-gate 范围

实现状态：本目录已有只读 MVP。未经独立 QA，不是发布，也不表示审查已通过。点子见 [IDEA.md](./IDEA.md)。

日期：2026-11-12（北京时间）。下文区分 2026-11-12 读到的草案形状和本项目已经实现的约定。

## 目标

做一个只读命令行工具。它读取一个或多个 skill 根目录，以及一份带服务器身份的快照，检查 `SKILL.md` 里的工具依赖。缺什么就非 0 退出。它不安装、不编排、不做安全扫描，也不探测 PATH，也不连接网络。

## 草案形状

[agentskills issue 485](https://github.com/agentskills/agentskills/issues/485) 的公开页面在 2026-11-12 读取时显示为 open，最近更新时间是 2026-11-01。页面上的提议是：

1. `dependencies.tools.all`：每一项都要可用。
2. `dependencies.tools.any`：至少一项可用。
3. `tools` 下面的裸列表是 `all` 的简写。
4. 判定偏软，未知名字不应让 frontmatter 解析失败。
5. 跨服务器工具身份仍未决定。

这次阅读只核对形状，不代表草案已被接受，也不是竞品复核。

## 本项目已经实现的约定

这些约定由适配层识别字段，匹配层只做全字判断。

1. `all` 里的每一项都要满足。`any` 里至少一项要满足。两组同时出现时，两组都要满足。一组满足不能盖过另一组的缺失。
2. 恰好一个 `requires-mcp-servers` 时，工具只在那一台服务器上查找。这是本项目的单服务器限定，草案没有保证这种绑定。
3. 没有服务器声明时，工具在全部已标识服务器的工具名集合里查找。
4. 多个不同服务器再加 `all` 或 `any` 时明确拒绝，不猜交叉积。
5. 只有服务器声明时，检查这些服务器是否出现，可以有多个。
6. 重复的技能名称都保留，并用路径区分。结果按传入的根目录顺序，以及路径排序。
7. 空目录、没有 `SKILL.md`、非法 frontmatter、非法 JSON、非 UTF-8、过大输入、符号链接和不可读目录都是输入错误。标准错误写明原因，进程不输出 Python traceback，也不把这种输入当成通过。
8. 快照必须是带整数版本和 `server` 字段的封装。原生 `tools/list` 会被拒绝，并在错误里给出一份可用封装例子。实现没有连接真实 MCP。
9. 退出码 0 表示全部通过。退出码 1 表示依赖缺失或声明尚不支持。退出码 2 表示输入错误。同一轮里只要有输入错误，结果就是 2，此时已满足的行会显示为未判定，避免部分满足盖过错误。

## 入口

在 `products/skill-deps-gate` 下执行。运行依赖是 `requirements.txt` 里的 PyYAML 6.0.1。`--skill` 可重复，`--snapshot` 只有一份。

1. 一个直接包含 `SKILL.md` 的目录会被当作一个 skill，不再把子目录当成别的 skill。
2. 一个不含 `SKILL.md` 的目录会向下查找其中的 `SKILL.md`，不跟随符号链接。
