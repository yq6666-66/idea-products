## 2026-11-12 只读 MVP

1. 增加只读命令，检查 `dependencies.tools.all`、`dependencies.tools.any` 和 `requires-mcp-servers`。
2. `all` 必须全部满足，`any` 必须至少一项满足。两组同时声明时，两组都要满足。
3. 恰好一个服务器时，工具只在该服务器上匹配。没有服务器声明时使用全局工具集合。多个服务器再加工具声明时拒绝，不猜交叉积。
4. 支持一个 skill 目录，也支持多个 skill 根目录。结果按路径稳定排序，并区分重复名称。
5. 空目录、非法 frontmatter、非法 JSON、非 UTF-8、过大输入、符号链接和不可读目录会给出输入错误，不以通过结束。
6. 快照要求显式服务器身份。原生 `tools/list` 会拒绝并给出封装例子。没有连接真实 MCP。
7. 增加本目录的 pytest 配置和开发依赖。仓库现有的产品测试工作流会在单独虚拟环境里运行它。
8. 没有修改 README，没有实现 PATH 探测、安装、编排、安全扫描或网络访问。

## 2026-11-12 符号链接入口

1. 独立 QA 在 `e52e762965cec23bc4cbf8341619493b8cba9c0f` 上发现：`--skill` 自身是有效目录符号链接时会退出 0 并显示满足。断链当时被报成找不到目录。
2. 现在按参数原文的每一段拒绝符号链接，包括目录链接、断链、祖先段，以及经过链接后再用 `..` 返回的路径。退出码为 2，不显示满足。
3. 扫描中发现的子目录链接、`SKILL.md` 链接，以及快照路径上的链接，仍然拒绝。
4. 不把这次差异写成审查已经完成。README 仍不在本轮修改。

## 2026-11-12 输入校验

这些改动来自对旧 head 审查意见的独立复现，不是审查已经没有阻断。

1. 描述里缩进的 `---` 不再被当成 frontmatter 结束，避免服务器声明被截掉后变成全局工具假通过。
2. 快照版本只接受整数 1，不再接受 `1.0` 或 `true`。
3. 嵌套目录无法读取时回传错误，整轮退出码为 2，不再忽略后通过。
4. 输入上限明确为 1048576 字节（1 MiB）。
5. 同一扫描根里既有合法 skill 又有扫描错误时，保留已发现的行并标为未判定，同时退出码为 2。
6. `SKILL.md` 和快照若不是普通文件，读取前拒绝。FIFO 不再挂起。
7. `license`、`compatibility`、`metadata`、`allowed-tools` 可以出现且不被解释。未知依赖组合仍然拒绝。这不表示支持完整规范。
