# QQ 拟人人设体检

给一个 LangBot / NapCat 机器人的整套人设配置做一次只读体检，回答它发出去的消息像不像群友。

## 用法

```bash
python3 audit.py <配置目录或 fixture 目录> [--json]
```

配置目录里放三样东西（只读读这三样，不碰目录外的东西）：

1. `prompt.txt`：人设提示词文本，一行一条规则。
2. `config.json`（可选）：模型参数与命令映射，例如 `{"temperature": 0.85, "top_p": 0.9, "max_tokens": 512, "commands": {"!唱歌": "sing"}, "quote_reply": false}`。
3. `simulated_replies.json`（可选）：模拟回复列表，例如 `[{"role": "xiao-shen", "text": "来了来了", "quote": false}]`。不放这个文件时，用内置的 5 条模拟群聊消息（问候、问问题、点歌、闲聊、@ 机器人）。

退出码：0 表示扫完（即使有问题也为 0，有问题写在表里）；2 表示目录不存在或不是目录。

## 检查项

1. AI 腔：规则词表加句式检查，例如“首先/其次/最后”“总的来说”“作为 AI”，命中即报原文行号；模拟回复里以数字加顿号或短横开头的行算列表式。
2. 碎话短句：按标点分句，单条超过 3 句或单句过长即报。
3. quote 回复：提示词或配置要求引用回复，或模拟消息带引用格式，即报。
4. 美咲句长：美咲式回复 1 到 2 句，超过 2 句或单句过长即报。
5. 唱歌点歌接线：触发词（例如 `!唱歌`、`@小深 唱歌`）缺失或映射到错误动作即报。
6. 模型参数：temperature、top_p、max_tokens 超出合理范围即报并给出建议值范围，不改参数。

判定细节：quote 检查只报要求引用的行，写“不引用对方”这类否定规则的行不误报；配置格式解析失败时对应检查项报“未核实”，不猜；句长上限写在 `checklist.md` 里，规则变了只改清单。

严重程度排序：唱歌接线错误与模型参数越界最高，其次是 AI 腔与 quote 回复，再次是句长与碎话，未核实排最后。

## 输出

默认按严重程度排序打表，每行写检查项、问题级别、位置、问题描述、改一句的建议，末尾一行汇总（检查 6 项，问题 X 条、未核实 Y 条）。加 `--json` 则输出同结构的对象数组。

示例（fixture 人设，唱歌接线缺失）：

```
| 检查项  | 级别 | 位置                   | 问题描述                     | 改一句的建议                          |
| ---- | -- | -------------------- | ------------------------ | ------------------------------- |
| 唱歌接线 | 严重 | config.json:commands | 触发词“!唱歌”缺失，没有映射到唱歌动作。    | 在 commands 里加上“!唱歌”: "sing"。    |

检查 6 项，问题 2 条（未核实 0 条）
```

## SKILL.md 与检查清单

1. `SKILL.md`：按 Claude Code skills 格式写，写清触发时机（改人设提示词之前、换模型参数之后、上群之前）、检查清单、输出格式、红线。
2. `checklist.md`：人设检查清单，把人设规则写成可检查的规则条目，每条带判定方法与建议改法；规则文件与提示词分开，规则变了只改清单。

## 红线

1. 只读：不改机器人配置、不改提示词、不发任何消息、不连 QQ、不点歌。
2. 只读用户指定的配置目录，不碰目录外的东西。
3. 公开版只用通用示例人设，绝不把用户的真实人设提示词写进 README、SKILL.md 或示例。
4. Python 标准库，不装依赖；Linux 与 Windows 都能跑。
5. 输出只给结论与改一句的建议，不替用户改提示词。

## 已知局限

1. 体检只看配置文本与模拟消息，不等于群里真实效果；真人群聊反应仍需用户自己看。
2. 打分标准以用户自己的人设规则为准，规则变了要同步改清单，清单与提示词不同步时会误报。
3. 配置格式可能随版本变，解析失败时报“未核实”，不猜。
4. 唱歌接线只查配置映射，不实际点歌、不连 QQ。

## 演示

```bash
python3 demo.py
```

演示只用临时 fixture 人设（一个健康人设、一个唱歌接线缺失的人设），打印体检表，跑完清理。

## 自测

```bash
python3 -m pytest
```

测试在临时 fixture 人设上跑：健康人设 0 问题；AI 腔报行号；4 句回复报碎话；带引用格式报；美咲 3 句同时报碎话与美咲句长；commands 删空报两条严重；temperature 1.5 报并给建议范围；汇总行数字与检查项数一致；跑前后 fixture 文件哈希不变；配置目录不存在时退出码为 2。
