# log-slimmer

只对你自己的日志目录做瘦身，先报出哪些文件最大，再决定压缩还是归档。

1. 用法：`python3 log-slimmer.py <目录> [--top N] [--plan --older-than-days D]`，按大小列出 `*.log`。
2. 只读：默认只列文件，不删、不压缩；`--plan` 只打印超过 D 天、会被归档的清单，仍不做任何动作，真正的压缩归档是后续版本，且要先备份、再经确认。
3. 边界：只扫你自己的目录，不指向备份或未知来源文件。

试跑：2026-11-01 在 Linux VM 上用假数据通过，最大文件排第一、`--plan` 正确标出超 30 天文件且全程未动文件；对 VM 的 /var/log 实测只找到 47 B 的 dpkg.log，超 30 天清单为 0 项。机器人、NapCat、Railway 这类真实日志目录仍需在产生日志的机器上单独跑，VM 结果不能冒充。
