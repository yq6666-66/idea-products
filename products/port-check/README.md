# port-check

输入端口就告诉你是谁占着，顺带列出常用开发端口的状态，不杀进程、不改配置。

1. 用法：`python3 port-check.py 7897 5173 3000`，先用 TCP 连接判断监听与否，再用 `ss -tlnp`（Linux）或 `netstat -ano`（Windows）找进程名。
2. 只读：找不到进程就写“进程未知”，不猜；只查命令行里给出的端口，不动其他配置。
3. 边界：本机结果只对运行它的机器有效。

试跑：2026-11-01 在 Linux VM 上，7897、5173、3000、8000、8080 均为 free，临时服务起起来后正确报出 LISTENING 和属主进程。Windows 上的 7897 代理端口和开发服务器端口仍需在 Windows 上单独跑，VM 上 7897 空闲不等于 Windows 上 Surge 的状态。
